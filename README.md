# جمجم | Jumjum V5

لعبة أسئلة ومعرفة عربية بنمط مغامرة، مع تجارب عمرية للأطفال ونظام منافسة مستقل.

## مرجع المنتج
- [دستور جمجم V5](docs/JUMJUM_V5_CONSTITUTION.md)

## التقنية المعتمدة
- HTML5 / CSS3 / Vanilla JavaScript
- Cloudflare Pages + Pages Functions
- Cloudflare D1 لبيانات اللعبة واللاعبين
- Cloudflare R2 للصور والملفات والوسائط
- Firebase Authentication لتسجيل الدخول فقط

## قاعدة الأمان
لا يتصل المتصفح بقاعدة D1 أو بحاوية R2 مباشرة. تمر عمليات البيانات عبر Pages Functions بعد التحقق من هوية Firebase وتطبيق صلاحيات الملكية. لا توضع مفاتيح أو أسرار خدمة في الواجهة أو Git.

## التطوير المحلي
قدّم مجلد المشروع إلى Cloudflare Pages أو استخدم Wrangler بعد تثبيته محليًا. لا توجد خطوة بناء للواجهة؛ ملفات الواجهة ثابتة.

## الحالة
مرحلة تأسيس النواة. راجع [خطة التخزين والبنية](docs/STORAGE_ARCHITECTURE.md) و[حالة قواعد البيانات](docs/DATABASE_SETUP_STATUS.md). لا تعد الأنظمة غير المنفذة مكتملة حتى تجتاز اختبارات القبول الواردة في الدستور.
