# جمجم | Jumjum V5

لعبة أسئلة ومعرفة عربية بنمط مغامرة، مع تجارب عمرية للأطفال ونظام منافسة مستقل.

## مرجع المنتج
- [دستور جمجم V5](docs/JUMJUM_V5_CONSTITUTION.md)

## التقنية
- HTML5 / CSS3 / Vanilla JavaScript
- Cloudflare Pages + Pages Functions
- Cloudflare D1
- Supabase للمصادقة وبيانات اللاعبين
- Firebase لمحتوى الأسئلة المنشور

## التطوير المحلي
قدّم مجلد المشروع إلى Cloudflare Pages أو استخدم Wrangler بعد تثبيته محليًا. لا توجد خطوة بناء للواجهة؛ ملفات الواجهة ثابتة.

## إعداد الأسرار
لا تضع مفاتيح Supabase أو Firebase أو Cloudflare داخل ملفات الواجهة أو Git. أضفها إلى إعدادات المشروع كمتغيرات/أسرار بيئية على الخادم فقط.

## الحالة
مرحلة تأسيس النواة. لا تُعد الأنظمة غير المنفذة مكتملة حتى تجتاز اختبارات القبول الواردة في الدستور.
