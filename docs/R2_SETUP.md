# R2 not selected

Cloudflare R2 is not part of the current Jumjum V5 architecture because the user's current Cloudflare setup requires a payment card.

Current image hosting is temporary through Servimg and FAMO-PIC. See `docs/STORAGE_ARCHITECTURE.md`.

Do not create an R2 bucket or add an R2 binding unless the user explicitly approves a future change and has an acceptable payment method.
